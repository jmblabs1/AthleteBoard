# AthleteBoard

A single-page tool for tracking college baseball players' stats (Batting, Pitching, Fielding). Pure HTML/CSS/JS in one file (`index.html`), no build step.

## Run locally
Open `index.html` in a browser.

## Branches
- `main` – live site
- `dev` – work in progress / test site

## Status
Prototype. Data is stored per-browser in `localStorage`; there are no accounts or shared database yet.
